# Python Activity-Based Learning

This repository contains 10 Python projects developed as part of the B.Tech First-Year Python Programming assignment.

### Projects
- Progressive Electricity Billing
- Employee Payroll Calculator
- Retail Billing System
- Attendance Recovery Calculator
- ATM Transaction Simulation
- Warehouse Inventory Management
- Student Marks Analysis
- Password Validation System
- Monthly Calendar Generator
- Bus Passenger Occupancy Simulation

### Technologies
- Python 3
- Visual Studio Code

**Purpose:** To develop logical thinking and practical programming skills using fundamental Python concepts.
