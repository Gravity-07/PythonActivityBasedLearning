This ZIP contains 10 beginner-friendly Python case studies selected from the supplied list of 100.

3. Retail Billing with Discounts

6. Warehouse Inventory Reconciliation

8. Password Policy Validation
9. Monthly Calendar Generator
10. Bus Passenger Occupancy Simulation

## How to use
- Extract the ZIP file.
- Open a project folder in VS Code or another Python editor.
- Run the `.py` file using Python 3.
- Read the folder's `README.md` for the problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, test cases, and conclusion.

## Notes
- The programs use beginner-level Python concepts from the supplied syllabus.
- Each program is standalone and accepts input from the user.
- The README files include test cases and sample-output guidance. They do not contain captured screenshots; capture screenshots of your own program runs before submitting if your faculty requires actual screenshots.
- Review the code and adapt names, assumptions, and formatting to your faculty's exact requirements before submission.
